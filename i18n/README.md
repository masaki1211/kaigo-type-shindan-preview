# 多言語（7言語）の運用マニュアル

このフォルダは、ケア図鑑の画面に出る文章を言語ごとにまとめた場所です。
**翻訳の運用ルールは、このファイルが唯一の正典です。**同じ説明を他の資料に書き足さないでください。

対応言語：日本語(ja) / 英語(en) / インドネシア語(id) / ベトナム語(vi) / 中国語(zh) / ネパール語(ne) / ミャンマー語(my) / シンハラ語(si)

---

## 1. ファイルの役割

| ファイル | 中身 | 触ってよい人 |
|---|---|---|
| `ja.static.json` | 画面に出る日本語（748件） | **日本語を直す人** |
| `ja.app.json` | 診断結果など、プログラムが組み立てる日本語（359件） | **日本語を直す人** |
| `en.json` `id.json` `vi.json` `zh.json` `ne.json` `my.json` `si.json` | 各言語の訳 | 翻訳担当 |
| `_snapshot.json` | 「その訳を作ったときの日本語」の指紋（ハッシュ） | **人は触らない**。ツールが自動で書き換える |

日本語のファイルは「キー: 文章」の形です。キー（`intro.title` など）は画面の場所を表す名札なので、**キーは絶対に変えないでください**。変えると画面から文章が消えます。

文章の中の `{n}` `{type}` のような **波かっこは差し込み口** です（施設名や数字がここに入る）。訳文でも**同じ波かっこをそのまま残す**必要があります。消すと画面表示が壊れます。

---

## 2. 日本語の文章を直したいとき

### 手順

1. 直したい文章を `ja.static.json`（画面の文言）か `ja.app.json`（診断結果の文言）から探す。
   - どちらにあるか分からないときは、両方のファイルで文章の一部を検索してください。
2. **キーはそのまま**、コロンの右側の文章だけを書き換える。
3. 保存したら、**必ず点検ツールを走らせる**（次の章）。

### なぜ点検が必要か

訳が無いキーは自動で日本語が表示されます（フォールバック）。
でも**日本語だけ直して訳を直さないと、訳は「存在する」ので古い訳が表示され続けます。**誰も気づけません。
それを見つけるのが点検ツールの仕事です。

---

## 3. 点検ツールの使い方

ターミナルで、`care-type-shindan` フォルダに移動してから実行します。

```bash
# 7言語まとめて点検（いつもこれ）
python3 tools/i18n-check.py

# 1言語だけ見たいとき
python3 tools/i18n-check.py --lang en

# 一覧を全部出したいとき（既定は各20件まで）
python3 tools/i18n-check.py --max-detail 0
```

追加のインストールは要りません（python3 だけで動きます）。

### 出てくる判定の意味

| 判定 | 意味 | どうする |
|---|---|---|
| 未翻訳 | 日本語にはあるが、その言語にまだ無い | 訳を追加する（当面は日本語が表示されるので、画面は壊れない） |
| 原文が変わった（要再翻訳） | 日本語を直したのに訳が古いまま | **いちばん大事。**次の章のテンプレで訳し直す |
| 差し込み記号の不一致 | `{n}` などが訳で消えた／増えた | **表示が壊れる。すぐ直す** |
| 余分なキー | 日本語側で消した文章の残骸 | `--fix-extra` で掃除する |
| 日本語の残留 | 訳の中にひらがな・カタカナが残っている | 訳し忘れ。訳す（漢字だけの場合は中国語として正常なので出ません。商品名「ケア図鑑」「ひとみ」は除外済み） |
| 空の値 | 中身が空っぽ | 訳を入れる、または行ごと消す |

問題が1件でもあれば「要対応」と出て、**終了コード1**で終わります（自動チェックに組み込めます）。問題ゼロなら0です。

### 掃除のコマンド

```bash
# 余分なキーを訳ファイルから削除（訳ファイルを書き換えます）
python3 tools/i18n-check.py --fix-extra
```

## 4. 「原文が変わった」と出たキーの訳し直し方

点検ツールが**キー名と現在の日本語原文**を一覧で出します。それをそのままAIに渡してください。

### AIへの指示テンプレート（コピーして使う）

```
ケア図鑑（介護施設の診断サイト）の多言語ファイルを更新します。
言語：〈英語 / インドネシア語 / ベトナム語 / 中国語 / ネパール語 / ミャンマー語 / シンハラ語〉

下のキーは日本語の原文が変わったため、訳し直しが必要です。
次のルールを守って、JSON（"キー": "訳文" の形）だけを返してください。

- 読み手は日本の介護施設で働く外国人スタッフと施設長。やさしく、失礼のない表現で。
- 波かっこ（{n} {type} など）は数も種類も原文と完全に同じものを残す。中の英字は訳さない。
- 「ケア図鑑」「介護のひとみ」は固有名詞なのでそのまま。
- 原文に無い情報を足さない。長さは原文と同じくらいに。
- 訳文にひらがな・カタカナを残さない。

〈ここに点検ツールが出したキーと日本語原文を貼る〉
```

返ってきたJSONを、その言語のファイル（例：`en.json`）の該当キーに上書きします。

### 訳し終わったら必ずこれ

```bash
# 点検して問題ゼロを確認
python3 tools/i18n-check.py

# 問題ゼロになったら、指紋を最新の日本語で記録し直す
python3 tools/i18n-check.py --snapshot
```

**`--snapshot` を忘れると、直したのに「原文が変わった」と出続けます。**
逆に、訳し直す前に `--snapshot` を実行してしまうと**古い訳が「最新」として記録され、警告が消えてしまいます**。順番に注意してください。

## 5. 新しい言語を追加するとき

やることは2つだけです。

1. このフォルダに `〇〇.json` を作る（例：タイ語なら `th.json`）。中身は `{}` でも構いません（訳が無いキーは日本語が出ます）。
2. `public/index.html` の言語メニューに1行足す。既にある行をまねするだけです。

```html
<a onclick="setLang('th','ไทย','🇹🇭',this)"><span class="flag">🇹🇭</span>ไทย<span class="check">✓</span></a>
```

3. `tools/i18n-check.py` の先頭の `LANGS` と `LANG_NAMES` に言語コードを足すと、点検の対象になります。

`app.js` の書き換えは不要です（言語コードから `i18n/〇〇.json` を読む作りになっています）。

---

## 6. まとめ（これだけ覚えれば大丈夫）

1. 日本語を直したら `python3 tools/i18n-check.py`。
2. 「原文が変わった」と出たキーを訳し直す。
3. 問題ゼロになったら `python3 tools/i18n-check.py --snapshot`。
